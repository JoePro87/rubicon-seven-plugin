# data/rules/ — Vaults of Vaarn rules data (CC BY 4.0)

The JSON in this directory (rules, tables, bestiary, equipment, gifts, lore,
mutations, bloomboons, transport speeds, etc.) is setting/rules data derived
from **Vaults of Vaarn** by **Leo Hunt**, transcribed and restructured into
machine-readable form for the engine.

endorsed by Leo Hunt. The rulebook PDF itself is **not** included — bring your
own copy of the official rulebook.
